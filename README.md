## Сайт на Astro — `site/`

Помимо книги ТЗ собран рабочий статический сайт: **273 страницы, 0 КБ JavaScript на клиенте**, сборка за 0,5 секунды.

```bash
cd site && npm install && npm run dev
```

SEO-аудит сборки (`python3 scripts/seo_audit.py`) — ноль дефектов по всем 273 страницам: нет пустых или дублирующихся title и description, у каждой страницы ровно один H1, canonical и микроразметка, нет битых внутренних ссылок и страниц без входящих ссылок.

Реализовано: `LocalBusiness` с координатами и зоной обслуживания, `BreadcrumbList`, `Service`, `Article`, `FAQPage`, `ItemList`; `sitemap-index.xml` со всеми 273 URL и приоритетами по вложенности; `robots.txt` с `Clean-param` под Яндекс; хлебные крошки; оглавления с якорями; на 152 страницах 8 и более H2.

Что нужно заменить перед публикацией — единым списком в `site/src/data/site.ts` и в `site/README.md`: бренд, домен, телефон, адрес, цены, реквизиты. Формы не подключены к обработчику, фотографий нет — их нужно снять, брать у конкурента нельзя.

## Три вещи, которые определяют приоритеты

**1. Хвост Вордстата — не запросы.** Из 78 замеренных фраз у 7 частотность в кавычках нулевая при заметной широкой: «правами можно ездить на квадроцикле» 643 → **0**, «хранение снегохода» 43 → **0**. Приоритет строится по узкой частотности. Ядро сверх ~1 850 наращивать не нужно — ТЗ прямо запрещает искусственное увеличение.

**2. Корпоративная ветка подтверждена цифрами.** «Тимбилдинг» 11 075 / **1 818** в кавычках, «корпоративные мероприятия» 2 311, «корпоратив в москве» 1 954, «новогодний корпоратив» 75 612 в декабре. Блокирующий вопрос HR — безнал и закрывающие документы — в выдаче раскрыт только в FAQ одного конкурента. Под него сделана отдельная страница.

**3. Алиса AI отвечает на все информационные запросы ниши** и молчит на транзакционных. Информационный раздел конкурирует не только за клик. Во все 150 ТЗ заложены прямой ответ в первом экране, «Коротко о главном», FAQ и раздел источников.

## Что осталось неопределённым

1. **Параметры площадки нового проекта** — парк техники, длина трасс, пропускная способность, цены, инфраструктура. Все ТЗ содержат поля, которые без этого не заполнить.
2. Частотность в кавычках измерена у 78 фраз; операторы `!` и `[]` не применялись.
3. Выдача проверена по 42 опорным запросам, а не по каждой принятой фразе.

Данные Вебмастера и Метрики больше не значатся ограничением: для нового проекта истории не существует ни у кого. Вместо этого — требование T20: **счётчик и Вебмастер подключаются до открытия индексации**.

## Порядок запуска

1. **Определить площадку и подтвердить 14 позиций** — цены, пропускная способность, условия для юрлиц, возрастные пороги, залог, условия сертификатов (лист «19 Материалы и факты»).
2. **Зафиксировать структуру URL** до наполнения — 273 адреса в листе «03 Структура». Менять после индексации дорого.
3. **Создать карточку Яндекс Бизнеса и подать заявку на welcome.mosreg.ru** — портал МО ранжируется в топ-10 по нескольким нашим запросам и для нового сайта это самый быстрый источник трафика.
4. **Каркас:** главная, каталог, корневая B2B-страница, 5 приоритетных услуг, 15 статей пилота. Пустой каркас в индекс не пускать (требование T26).
5. **Новогодний блок — до конца августа.** Спрос на «новогодний корпоратив» стартует в сентябре и достигает пика в декабре.
6. Правовой хаб H01 без юриста не публикуется: ни одна цифра — без ссылки на первоисточник и даты проверки.
