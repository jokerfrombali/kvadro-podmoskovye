# Сайт проката внедорожной техники — Astro

Статический сайт на **Astro 5**, собранный по семантическому ядру и книге ТЗ из `../out/`.
**273 страницы, 0 КБ JavaScript на клиенте**, сборка за ~0,5 секунды.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

## Что реализовано по SEO

- **Микроразметка на каждой странице:** `LocalBusiness` с адресом, координатами и зоной обслуживания; `BreadcrumbList`; `Service` на услугах; `Article` на статьях; `FAQPage` и `ItemList` на главной.
- **`sitemap-index.xml`** — все 273 URL с приоритетом по уровню вложенности (1.0 → 0.6) и `lastmod`.
- **`robots.txt`** с `Clean-param` для utm-меток, yclid и gclid — это учитывает именно Яндекс.
- **Канонические адреса** на всех страницах, `trailingSlash: always` — один вариант URL без дублей.
- **Хлебные крошки** с микроразметкой на всех внутренних страницах.
- **Структура под ИИ-ответы:** на 152 страницах 8 и более H2, оглавление с якорями, блок «Вопросы и ответы». Замеры показали, что блок «Быстрый ответ Алисы AI» выводится на всех информационных запросах ниши.
- **Перелинковка:** хаб ↔ статья, услуга → база знаний, соседние страницы раздела, подбор релевантных статей по пересечению лексики.
- Семантический HTML, `lang="ru"`, skip-link, `:focus-visible`, `prefers-reduced-motion`.

## Архитектура кода

```
src/
├── data/
│   ├── site.ts        ← ЕДИНЫЙ КОНФИГ: бренд, телефон, адрес, цены
│   ├── copy.ts        ← развёрнутые тексты приоритетных страниц
│   ├── pages.json     ← 111 коммерческих страниц (из книги ТЗ)
│   ├── hubs.json      ← 12 хабов
│   └── articles.json  ← 150 статей с планом H2–H3
├── lib/tree.ts        ← дерево страниц, крошки, подбор связей
├── layouts/Base.astro ← SEO-голова, микроразметка, шапка, подвал
├── components/        ← Header, Footer, Breadcrumbs, LeadForm, Icon,
│                        PageCommercial, PageHub, PageArticle
└── pages/
    ├── index.astro    ← продающая главная (14 экранов)
    ├── [...slug].astro← все 272 остальные страницы
    └── robots.txt.ts
```

Данные приходят из книги ТЗ: `python3 ../build/export_site.py` пересобирает JSON из `build/d_*.py`.
Меняете структуру в книге — обновляете JSON — сайт пересобирается.

## ⚠️ Что нужно заменить перед публикацией

Всё собрано в **`src/data/site.ts`** и помечено комментарием `ЗАМЕНИТЬ`:

- **Бренд** «ОФФТРЕК» и домен `example.ru` — рабочие плейсхолдеры
- **Телефон, почта, адрес, координаты** — заглушки
- **Цены** — рыночный ориентир по замерам конкурентов на сентябрь 2026, не подтверждённый прайс. На странице цен выводится видимое предупреждение об этом
- **Цифры о базе** (100 км трасс, 15+ единиц техники, 50 км от МКАД) — из сайта-образца, требуют подтверждения
- **Реквизиты юрлица**

Дальше:

- **Формы не подключены** к обработчику — требования T18 и T19 в листе «22 Техника и CMS». Сейчас выводится честная пометка прямо в форме.
- **Фотографий нет.** Ни одной. Брать с сайта конкурента нельзя — нужна своя съёмка. Задания на съёмку есть в каждой карточке ТЗ.
- **Текст написан для 6 приоритетных страниц** (`src/data/copy.ts`): корпоративный корень, корпоратив на квадроциклах, прокат квадроциклов, документы и безнал, цены. Остальные страницы рендерят утверждённую структуру с пометкой «текст в работе» и задачей раздела для автора — это не заглушка, а рабочее ТЗ прямо на странице.
- **Счётчик Метрики и Вебмастер** подключить ДО открытия индексации — требование T20.
- **Не открывать индексацию пустого каркаса** — требование T26.
